# MM-RAG-Industrial

工业技术文档多模态问答系统 | 基于 RAG、SFT 与 DPO

## 项目简介

MM-RAG-Industrial 是一个面向工业技术文档的多模态问答系统，针对以下挑战：

- 图片型 PDF 难解析  
- 图文信息需协同融合  
- 复杂文档结构与机械原理推理  

项目构建了一个端到端多模态 RAG 系统，并结合 SFT 与 DPO 优化模型能力。在测试集上的评测指标如下：

- **BERTScore** (语义相似度)：0.85  
- **ROUGE-1** (词级重合度)：0.62  
- **EM** (精确匹配)：0.30  

---

## 技术栈

MinerU · LangChain · Milvus · LoRA · DPO · RAG  

---

## 核心模块

- **多模态文档解析**：  
  使用 MinerU 将工业 PDF 文档结构化为 Markdown，并将图像转化为可索引路径，支撑多模态检索。  

- **多模态 RAG 构建**：  
  基于 LangChain + Milvus，实现图文动态查询路由机制，并构建标注数据集进行系统化评测。  

- **VLM 指令微调**：  
  使用 LoRA 对 Qwen2.5-VL-7B-Instruct 进行指令微调；扩充相对空间关系理解训练样本，实现可控数据增强。  

- **DPO 偏好优化**：  
  针对验证集 BERTScore 较低样本构造偏好对进行 DPO 训练，提高模型在工业问答场景下的专业性与一致性。
